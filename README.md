# Python Digital Clock

A digital clock application built in Python using Tkinter.

## Features
- Real-time digital clock display
- 12-hour and 24-hour formats
- Lightweight and responsive GUI

## Why This Matters
Demonstrates:
- Real-time updates in Python
- GUI programming with Tkinter
- Clean, user-friendly interface

## Tech Stack
- Python (3.11+)
- Tkinter

## Quickstart
```bash
git clone https://github.com/thalia241/python-digital-clock.git
cd python-digital-clock
python clock.py
